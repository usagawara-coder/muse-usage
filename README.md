# muse-usage

Muse usage data for an iPhone Scriptable widget.

- File: `muse-usage.json`
- Contents: used %, remaining %, weekly reset time, plan name only. No personal data, no tokens.
- Updated automatically every 3 hours by Muse (Shiro).
- Raw URL: https://raw.githubusercontent.com/usagawara-coder/muse-usage/main/muse-usage.json
